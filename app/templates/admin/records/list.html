Editing reuses the same form, filled in, and the row being edited is named in the panel heading so it is never ambiguous which record "Save" applies to. EVERY ROW'S CONTROLS ARE FORMS Deactivate and edit are POSTs, so a stray link prefetch cannot deactivate a record.
