IT ANSWERS THREE QUESTIONS, IN THIS ORDER The layout is the order of attention, not a grid of equally-weighted boxes: 1. **Is anything blocked?** The tiles. The one that matters — consented but with no recorded date, so nothing publishes — is marked gold and explained in words, because it is the only consent state that is both invisible and blocking (§5.6, §5.3 rule 3). 2. **What changed recently?** The audit table. Every write in this panel lands there, so it is the honest answer to "did something happen overnight". 3. **What is waiting on me?** The message queue and the backup state. THE BUCKETS ADD UP, AND THAT IS THE FEATURE Five states and a total, and the five sum to it. Anyone can see at a glance that nobody has been lost between the categories — which is the only reason to trust the number next to "awaiting consent" enough to act on it. AN EMPTY SYSTEM SHOWS ZEROS Every tile is a COUNT, and a COUNT over nothing is 0.
