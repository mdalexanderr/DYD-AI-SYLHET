{# ============================================================================= admin/_icons.html — the inline SVG set for the panel. WHY INLINE SVG AND NOT AN ICON FONT OR A SPRITE §7.4 forbids icon fonts and emoji, and §15.1 allows no JavaScript anywhere in this project — so there is no icon library to load and no runtime to swap a symbol by name. A macro per icon is the only option that keeps the icons server-rendered, content-hashed with the template, and free of an extra request. WHY THEY ARE 24px GRID / 1.5 STROKE, NOT 16px / 2 STROKE The chevron-and-square families that ship with most icon sets are drawn for 16px and turn to mush beside 13px admin text at the 1rem the rail uses. These are drawn on a wider curve with a thinner stroke so they survive being scaled down and still read at the 1.5rem used in the empty states. EVERY ICON IS aria-hidden BY DEFAULT They sit beside text that already says what the link does. An icon announcing itself as well produces "Media library, image, link" in a screen reader. The one exception is documented where it is used. ============================================================================= #} {% macro icon(name, size='size-4') %} {% endmacro %}
